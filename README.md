# Çaydanlığa Aşk Mektubu Yazan Bardak

## Resmî Beyanname

Bu yazılım, mutfak eşyaları arasındaki iletişim krizine bilimsel müdahaledir.
Yüzyıllardır çaydanlık kaynar, bardak bekler. Kimse bu sessizliği belgelemedi.
Artık belgelendi.

Bardak konuşur. Çaydanlık dinler. Sen izlersin.

## Kuruluş Amacı

1. İnce belli bardakların duygusal haklarını korumak.
2. Kaynama süresini edebî bir bekleyişe çevirmek.
3. Mutfakta sessizliği resmî törene dönüştürmek.

## Kurulum

```bash
python3 bardak.py
```

Başka bir şey gerekmez. Çünkü aşk da bağımlılık istemez. Sadece Python 3 yeter.

## Kullanım Protokolü

Program çalıştığında:
- Bardak kalemi eline alır.
- Rastgele ama kader gibi duran bir mektup yazar.
- Mektubu yavaş yavaş, sanki buhar üzerinden okur gibi basar.

Çıktıyı çaydanlığın yanına bırakmanız tavsiye edilir. Etki artar.
